# Wiyaflow

A personal finance app built with Flutter and Firebase that lets you log, categorize, and visualize your expenses — with full dark mode support.

---

## Screenshots

> Run the app and explore — light and dark themes are both fully supported.

---

## Features

### Authentication
- Email & password sign-up and login via Firebase Auth
- Persistent session — stays logged in across app restarts
- Form validation with user-friendly error messages

### Expense Management
- Add, edit, and delete expenses
- Each expense has: **amount**, **category**, **note**, and **date**
- Expenses are stored per-user in Firestore (isolated by UID)

### Home Screen
- Monthly expense summary card showing total spend for the current month
- Real-time list of expenses for the selected month
- Month selector to navigate between months
- Tap any expense to edit or delete it

### Filtering & Search
- **Search** expenses by note text
- **Filter by category** (Food, Transport, Bills, Shopping, Health, Entertainment, Other)
- **Filter by date range** with a custom date range picker dialog
- All three filters work together simultaneously
- One-tap clear to reset all filters

### Insights Tab
- **Pie chart** showing spending breakdown by category
- **Bar chart** showing category totals with smart Y-axis scaling
- Category percentages and totals listed below the charts

### Dark Mode
- Full dark/light theme toggle persisted via `shared_preferences`
- Calendar, charts, dialogs, and all screens respect the active theme

## Project Setup

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) ≥ 3.13
- Android Studio or VS Code with Flutter extension
- A Firebase project with **Authentication** (Email/Password) and **Firestore** enabled

### 1. Clone the repo

```bash
git clone <repo-url>
cd expense_tracker
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Firebase configuration

The Firebase config files are already committed and point to the project's Firebase backend:

- `lib/firebase_options.dart` — generated by FlutterFire CLI
- `android/app/google-services.json` — Android config

> **Note:** These files contain public client identifiers, not private keys. Your data is protected by Firebase Auth (each user only sees their own data) and Firestore security rules, not by keeping these files secret.

### 4. Run the app

```bash
# List connected devices
flutter devices

# Run on your Android device
flutter run -d <device-id>

# Or simply (if only one device is connected)
flutter run
```

### 5. Build a release APK

```bash
flutter build apk --release
```

The APK will be at `build/app/outputs/flutter-apk/app-release.apk`.

## Folder Structure

```
lib/
├── core/
│   ├── constants/       # Category enum and labels
│   └── theme/           # AppTheme (light/dark) + ThemeProvider
├── features/
│   ├── auth/
│   │   ├── data/        # FirebaseAuth repository
│   │   ├── presentation/ # Login & Signup screens
│   │   └── providers/   # Auth state providers
│   └── expenses/
│       ├── data/        # Firestore repository + Expense model
│       ├── presentation/ # Screens (Home, AddEdit, Insights) + Widgets
│       └── providers/   # Riverpod providers for expenses, filters, summary
└── main.dart
```
